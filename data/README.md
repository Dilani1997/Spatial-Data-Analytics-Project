# Data folder

Place only approved GeoQueryBench data here.

For the expanded workspace the default locations are:

- `data/geoquerybench_questions.csv`
- `data/_manifest.csv`
- official result files referenced by `_manifest.csv`

You can override these with:

- `GQB_EXPANDED_QUESTIONS`
- `GQB_GOLD_DIR`

Do not commit client data to a public repository. Keep the repository private unless the client/facilitator explicitly approves publication.
